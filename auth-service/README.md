# BidVelocity Auth Service

## Purpose

Handles user registration, authentication and JWT generation.

## Port

8081

## Responsibilities

- User registration
- Password encryption
- User authentication
- JWT generation
- Role management
- Authentication validation

## Database

bidvelocity_auth

## Main APIs

POST /api/auth/register
POST /api/auth/login

## Technology

- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- MySQL
- Eureka
- Java 21
